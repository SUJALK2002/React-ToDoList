
# 📝 React Todo App

A modern and responsive **Todo List application built using React**. This project helps users manage daily tasks efficiently with a clean dark-themed interface and smooth user experience. It is a beginner-friendly project focused on understanding React fundamentals such as components, state management, and event handling.

## 🚀 Features

* Add new tasks
* Delete tasks
* Mark individual tasks as completed
* Mark all tasks as completed at once
* Dark theme user interface
* Smooth hover effects and animations
* Unique task identification using UUID

---

## 🛠️ Technologies Used

* React (Functional Components & Hooks)
* JavaScript (ES6)
* CSS (Dark Theme Styling)
* Vite
* UUID
